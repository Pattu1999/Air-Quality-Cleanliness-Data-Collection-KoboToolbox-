# Air-Quality-Cleanliness-Data-Collection-KoboToolbox-
This project demonstrates the deployment and configuration of a KoboToolbox server to host environmental survey forms. The survey enables collection of geolocation-based observations, multimedia inputs (photos), and user-perceived air quality data.

Objective:

Provide a platform to collect field survey data on air quality and cleanliness.

Share survey URL with users for real-time data submission.

Make collected data exportable in Excel for future analysis.

Live Survey URL: https://ee.kobotoolbox.org/x/pdQMh9b0



Features:

Hosted KoboToolbox server accessible via public URL.

Survey form includes fields:

Respondent Name

Location (Latitude & Longitude)

Type of Area (Residential, Industrial, Market, Highway, Park)

Visible Dust or Smoke (None, Light, Moderate, Heavy)

Garbage Seen Nearby (Yes/No)

Is there a dustbin nearby, but still garbage? (Yes/No/Not Sure)

Smell Intensity (None, Mild, Strong)

Perceived Air Quality (1–10 scale)




Real-time submissions captured via web or KoboCollect.

Data export available as Excel/CSV for further visualization and analysis.

Sample Form and Sample exported data attached in repository.
